### Software Desktop e Web da empresa UandA





##### Sobre:



* **Linguagens utilizadas: Java, JavaScript, HTML e CSS**
* **IDEs (ambientes de desenvolvimento integrado) utilizados: Apache NetBeans e VS Code**
* **SGBD (sistema de gerenciamento de banco de dados) integrado ao software: MySQL**
* **Sistema de controle de versão para o software: Git**
* **Plataforma online para hospedagem e gerenciamento do versionamento: GitHub**



**Software desenvolvido por: Filipe de Jesus dos Santos**

Este software foi desenvolvido como Projeto Integrador do curso EaD em Técnico de Desenvolvimento de Sistemas, oferecido pelo Senac-RS



O sistema UandA é um software, com uma versão para desktop e uma para web, simples criado para a empresa brasileira fictícia de adoção de animais de estimação e de venda de animais de produção de mesmo nome. O objetivo de sua criação é a melhora da experiência do usuário e o favorecimento dos negócios da empresa. Nele, os usuários poderão visualizar os animais que estão disponíveis ou à venda em um determinado estabelecimento da empresa para comprá-los ou para adotá-los. Os estabelecimentos disponibilizam para adoção desde *pets* como cachorros, gatos, coelhos e peixes até animais para criação em fazendas, para abate, para produção de leite ou para produção de ovos, como galinhas, carneiros, porcos e vacas.



Para acesso do software, o cliente não precisa de cadastro, sendo isto apenas necessário aos funcionários e aos gerentes da empresa. A navegação no sistema foi feita pensando-se na facilidade e na praticidade pelo usuário, onde este pode escolher, na tela de localidades, em que estabelecimento físico irá querer visualizar a disponibilidade de animais e, então, navegar e buscar por aquele(s) de interesse na tela de busca de animais.





##### Como usar:



**Observação:** Boa parte das funcionalidades do sistema não funcionarão corretamente caso você não tenha a base de dados utilizada pelo software em seu dispositivo. Portanto, recomendo que leia o arquivo DATABASE.md para mais informações.



Para executar o software em seu computador, você precisará ter a JVM (Java Virtual Machine) de versão 25 ou superior instalada e configurada. Caso não possua, basta instalar e configurar o JDK (Java Development Kit) de versão 25 ou superior por meio de sites confiáveis na internet (recomendo que busque por tutoriais na internet). Com isso, você poderá rodar os executáveis .jar e usar o software!



Dentro do software, você poderá realizar login na tela inicial como um moderador, tendo acesso a funções ocultas para clientes, como poder inserir dados no banco de dados. Caso utilize o software sem fazer login e não tenha inserido nenhum registro no banco de dados além dos presentes no código do arquivo DATABASE.md, é normal que as telas de exibição de localidades e de animais venham sem conteúdo, visto que ainda não existem registros destes na base de dados. Contudo, realizando login como funcionário ou como gerente, você poderá acessar as telas para salvar animais e localidades no sistema. Caso entre como gerente, que possui o nível de acesso mais alto, você poderá desfrutar de todas as funcionalidades do sistema, incluindo a de criar novos moderadores. Logo, recomendo que faça login como gerente.



Para realizar login com o perfil pré-salvo de gerente no sistema, utilize, na tela de login, o seguinte Número de Cadastro e Senha, respectivamente: 999999 e 123456. Já para realizar login com o perfil pré-salvo de funcionário, utilize como Número de Cadastro e Senha, respectivamente: 111111 e 123321. Por fim, aconselho que execute sempre as versões mais recentes lançadas (pode executar as antigas, mas possivelmente você se depare com algum problema ou sinta falta de alguma funcionalidade). Espero que você goste do software e possa aproveitar de tudo o que ele tem a oferecer!
